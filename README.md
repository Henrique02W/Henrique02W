### 🧩 Ecossistema de Plugins Minecraft

Um conjunto de plugins que se integram entre si para formar uma experiência completa de servidor:

| Projeto | Descrição |
|---|---|
| 🔗 [**Crazycord**](https://github.com/Henrique02W/Crazycord) | Vinculação Minecraft ↔ Discord, sincronização de cargos, relay de chat e recompensas |
| 💬 [**NexusChat**](https://github.com/Henrique02W/NexusChat) | Canais de chat (global/local/staff) com MiniMessage e relay para Discord via webhook |
| 🏷️ [**UltimateTags**](https://github.com/Henrique02W/UltimateTags) | Plugin de tags moderno com Adventure/MiniMessage, GUI, storage async e animações |
| 🐚 [**AdvancedCustomSpawners**](https://github.com/Henrique02W/AdvancedCustomSpawners) | Spawners customizados com upgrades, combustível, armazenamento e roteamento de drops |
| 🏛️ [**DisplayAuctionHouse**](https://github.com/Henrique02W/DisplayAuctionHouse) | Auction House com pedestais físicos no mundo, sem GUI |
| ⚡ [**FutureTech**](https://github.com/Henrique02W/FutureTech) | Addon Sci-Fi para Slimefun4 com geradores de energia progressivos |
| 🧪 [**SlimeFunTweak**](https://github.com/Henrique02W/SlimeFunTweak) | Addon para ajustar receitas, crafting e máquinas de qualquer item do Slimefun4 |
